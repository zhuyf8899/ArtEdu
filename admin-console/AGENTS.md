# 学习界面约定

2026-10-29，用户批准将重复的课程库和原子库界面整合，沿用所提供第二张截图的 MORPH 浅紫色、白卡、深色按钮及原始插画。

- 学习区主导航使用“完整课程 / 学习原子”；“我的学习”提供快捷入口，贡献、上传、审核及评价按角色收进“学习与管理”。
- 原有试学课程并入完整课程目录，保留原课程 ID、课时、真实进度及深链接；不得按同名标题合并不同资源或复制进度。
- 课程网络默认收起，展开必须完整显示原有插画、连线及操作按钮；分类、搜索和进度控件维持一致布局。
- 卡片明确区分试学、知识大纲和筹备内容。原子进入自身详情，再按真实关系查看所属课程。
- 当前课程路径建议是规则推荐，按钮不得暗示已经调用个性化 AI 模型。
- 新页面继续使用已有权限、附件、审核和学习记录接口；保留无障碍名称、焦点样式与已有受保护的 Sites 运行文件。
