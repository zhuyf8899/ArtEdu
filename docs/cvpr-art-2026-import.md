# CVPR Art 2026 案例整理（2026-10-13）

从用户指定的 https://thecvf-art.com/archive.php?year=2026 整理10个作品，数据清单位于 `seed/cvpr-art-2026/cases.json`。每项包含中文编辑导读、原作者、已公开的工具和方法、教学讨论问题，以及原作入口。未公开的提示词、版本与参数不补造。

原站声明版权保留，未确认平台转载授权，因此本轮仅保存待授权草稿，不设置精选、不提交审核、不发布；不下载或重新分发图片和视频。图片与视频保留外部链接，访问情况受原站和网络环境影响。网页检索工具可以读取2026档案及详情，但本机直接请求2026作品页面曾跳转到2025档案，需在正式内容审核时再次检查链接可用性。

导入仅允许 localhost 数据库，使用现有 `admin.demo` 作为整理者，原作者单独保存在结构化故事字段。稳定ID、事务、导入锁与冲突检查支持重复运行；已有同ID案例不会覆盖。原有案例不改动。

在 `apps/api` 目录执行：

```powershell
npm run build
node scripts/import-cvpr-art.mjs
node scripts/import-cvpr-art.mjs --apply
```

默认预检；`--apply` 才保存本地草稿。数据库连接读取本地 `.env`，不写入清单或日志。草稿在管理员账号的“我的案例”及审核人员可访问的详情中查看；公开社区列表不展示未发布案例。

案例详情同时修复原有外部资源地址被错误拼接为本地文件下载地址的问题，相关内容提供“查看原始资料”入口。
