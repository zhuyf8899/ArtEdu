## 已开发的改进

| 优先级 | 问题与依据 | 本轮处理 |
| --- | --- | --- |
| P1 | 搜索中的“查看案例”只打开社区列表；作品详情刷新后不能保留 | 搜索与社区统一使用 `/community?work=作品ID`；支持直接打开、刷新、返回列表及错误重试。工作流搜索也携带具体工作流 ID |
| P1 | 外部案例的搜索结果把上传账号作为作者，无法用原作者名字找到作品 | 优先显示作品公开创作者，检索公开的创作者、方法与工具；不把授权备注等后台私有内容加入检索 |
| P2 | 搜索结果受固定图片宽度挤压，较窄桌面窗口中文近似竖排 | 在 821–1150px 桌面宽度使用上下式结果卡，正文保留合理宽度；整理排序、标签和说明字号 |
| P2 | 学习详情已有进度，目录卡仍可能显示未开始；首页统计可能只取最高课时进度 | 保留上一轮的统一进度计算与列表同步修复；首页聚合改为计入未学习课时的平均值。我的课程区分未开始、进行中、已完成与历史课程 |
| P2 | 没加入课程的账号被提示“清除筛选”，操作无意义 | 分开“尚未加入课程”和“筛选没有匹配”两种状态；首次使用提供“发现原子课程”入口 |
| P2 | 私有草稿或工作流服务异常会连带清空正常的公共案例列表 | 公共目录与辅助数据分开处理，辅助失败时保留公共案例并提供重新同步；401/403 仍传播，不绕过权限 |
| P2 | 点赞/收藏后列表计数不及时；重复点击容易重复请求 | 添加操作中保护，将返回的作品同步到已有详情和列表；不会把私有草稿追加进公共列表 |
| P2 | 编排路径第一门可能筹备中，用户不知道下一步学什么 | 显示现在可学/筹备中的数量，增加“从可学课程开始”，跳过尚未开放和历史课程；不自动加入课程 |
| P2 | 个人空间紧凑头部额度文字挤成多行；笔记占位文字过淡 | 整理额度区域布局，表单字号与占位文字对比度统一 |
| P2 | 配置存在但执行关闭时，被描述成“模型未配置” | 账户与我的空间统一说明当前本地演示状态，不把配置数量等同于可执行能力 |
| P3 | 登录说明在深色背景上对比度不足；深色工作流预览出现白色进度块 | 使用限定作用域的样式修复，保持原交接包主体风格 |

## 后续开发建议（尚未实施）

1. **后台处理效率**：课程管理增加标题/状态筛选，历史与筹备内容分组；统一后台辅助字号，减少行内操作拥挤。后续再考虑批量操作，发布/删除仍保留权限与确认。
2. **编辑与写入可靠性**：计划、笔记、案例编辑增加未保存离开提醒、明确保存中/失败恢复；工作流目录加载增加独立重试状态。应使用专用测试账号/数据验收真实写入，不在公开案例上试操作。
3. **目录与搜索规模化**：统一“灵感与素材/灵感与资源”等近义分类；增加服务端分页和筛选后总数，避免未来内容超过单类检索上限时造成误解。当前前端作者/工具筛选作用于已返回结果，应明确这一边界。
4. **学习闭环与能力依据**：继续完善试学教研审核、作品提交反馈和课程—工具—案例关联；专业画像以真实完成课时和实践证据呈现，不用报名数量或外部工具链接点击冒充能力认证。
5. **创作空间统一**：现有七模式功能入口已检查，但编辑工作区与 MORPH 风格仍有差异，可独立一轮统一布局、生成状态与产物管理；模型执行、额度和安全权限不随视觉改版自动放开。
