# 恢复默认课程图谱与加载修复（2026-10-12）

## 前端调整

- `/my-learning` 默认直接显示原有十门课程圆形总图，不再显示空知识库、学习路径表单等中间页面。
- `?atlas=reference` 保持兼容；`?atlas=course&atlasCourse=...` 仍进入各课程独立分图；`?atlas=personal` 保留原有个性化图谱。
- 未修改图谱圆形样式、课程知识内容、学习记录或后台知识管理接口。
- 保留未挂载知识库组件的错误/空状态提示和参考图谱入口，供后续重新接入时使用；该组件不再作为默认学生前端。

## 加载问题与部署要求

此前接口 500 的原因是本机代码更新后未执行新增迁移，缺少 `knowledge_nodes` 等表。已在本地补齐仓库既有迁移，没有重建数据库或重新播种数据。

就绪检查现在核对知识图谱所需表、来源字段和标签同步函数；迁移缺失时返回 503，避免将无法完整使用的 API 标记为就绪。

部署者仍须在目标数据库执行：

```sh
npm run db:migrate
```

代码上传不会替部署者自动修改远程数据库。通用课程图谱不依赖个人知识库数据；个人进度仍以真实学习记录为准。

## 验证与提交边界

- 增加默认图谱组件、课程分图路由及空状态入口的回归检查。
- 增加知识迁移缺失时就绪检查失败的测试。
- 合并前执行根目录 `npm run check`，并等待 GitHub PR CI 通过。
- 本地四个演示账号登录及四个知识接口验证通过；真实数据库知识闭环 11 项验收通过，验收数据整体回滚。
- 不提交 `.env`、密钥、数据库文件、本地截图、案例原文或临时目录。
