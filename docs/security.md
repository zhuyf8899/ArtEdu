# ArtEdu 安全基线

## 当前已实施

- 新 API 默认要求登录，只有健康检查显式匿名。
- 本地账号登录必须显式设置 `ENABLE_LOCAL_AUTH=true`，且生产环境会拒绝启动该开关；所有请求均使用服务端会话，不接受 `x-user-id` 等身份头。
- API 限制请求体为 1 MiB，提供本地限流、随机请求追踪 ID、统一错误响应和安全响应头。
- 管理员专属操作（账号停用、额度修改）仅允许 `admin`。
- 未接入模型适配器时拒绝创建或领取生成任务；任务引用必须经所有权或发布状态校验。
- 生产前端默认禁用测试身份；依赖安全审计和安全回归测试已接入 CI。

## 上线前仍必须完成

- 接入学校 SSO/OIDC 和密钥管理服务，禁止使用本地示例数据库密码。
- 对象存储上传必须使用受限签名、MIME/大小校验与恶意文件审核。
- 多实例部署必须使用网关或 Redis 共享限流，并配置可信反向代理。
- 启用模型后实施模型最小权限、调用审计和输出内容审核。
