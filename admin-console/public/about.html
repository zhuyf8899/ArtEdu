Open-source Packages

ArtEdu is built with, and gratefully relies on, the following key open-source packages:

  • React & React DOMInterface rendering
  • ViteFrontend development and build tooling
  • @xyflow/reactWorkflow canvas
  • @phosphor-icons/reactInterface iconography
  • react-markdown & remark-gfmMarkdown rendering
  • @fontsource/noto-sans-sc & space-groteskTypography
  • NestJS & FastifyAPI service framework
  • PostgreSQL driver (pg)Database connectivity
  • Zod & RxJSValidation and asynchronous processing
  • docx & PptxGenJSOffice document generation
  • Puppeteer CoreBrowser-based document rendering
  • dotenv & TypeScriptConfiguration and development tooling
