# 知识图谱业务第一阶段：明确配置与真实证据

## 已实现

- `/admin/courses` 的每门可管理课程增加 **图谱配置**。课程整体知识范围与各课时知识点分别填写，支持多行、逗号分隔与去重；每项最多 20 个名称、每个名称最多 80 字。
- `PUT /api/admin/courses/:courseId/knowledge-bindings` 只修改课程/课时的 `knowledge_points`。沿用管理员、教师、运营管理角色；非管理员只能管理自己创建的课程。锁定课程与所属课时、拒绝跨课程课时 ID、重复课时和额外字段。
- 草稿、驳回和已发布课程可配置，审核中与归档课程不可配置。已发布内容的知识配置属于独立、即时生效的元数据，不重新发布课程正文，不改课时 ID、学习进度、作业或原件；写入 `update_knowledge_bindings` 审计记录。未来若知识配置需要教学审核，可另加审核版本流程。
- 工作流编辑器增加折叠的 **学习图谱关联** 区，填写知识点、工具和能力目标。配置保存在 `workflow_versions.definition_json.learning`，遵循既有版本发布权限；本机草稿、导入、导出和读取均保留配置，运行记录按实际执行的版本展示。
- 学习空间只读取本人已选、未退课的已发布课程与课时，并带回本人关联作品。工作流配置读取本人运行记录绑定的版本，不能用后来的发布版本覆盖历史。
- 我的学习保留阶段圆形图谱。课时分支优先显示明确配置的知识点；下方增加 **知识与实践关联**，可按选中的课程或课时查看知识记录、完成数量、对应课时、已提交作品和工作流配置。默认最多六个知识卡，可展开全部。
- AI 讲堂课程详情同步显示课程知识范围与课时知识点。
- 课程学习建议优先定位到明确绑定、尚未完成的对应课时，显示完成数量与推荐理由；未配置用户沿用原有建议。
- 修复管理端课程详情未完整返回学习步骤、练习、完成标准和作品提交门槛的问题，避免编辑时覆盖已有教学设置。

## 数据与评价边界

- 没有自动给真实课程填知识点，也没有自动修改任何人的学习记录。历史内容默认空配置，需教师/管理员确认填写。
- 课程范围不直接产生知识点进度：必须有具体课时绑定。一个知识点对应多个本人可见课时，仅当这些关联课时全部完成才显示“关联课时已完成”，不是“已掌握”。缺失进度按未开始处理。
- 阶段色彩文案改为“目标达成 / 持续积累 / 已经开始 / 暂无记录”，表达累计记录目标，不是能力认证。
- 工作流“涉及工具”和“能力目标”只是版本配置。点击外部工具、开始运行或完成工作流都不能证明外部工具实际使用或能力达标。
- 作品仅显示本人已关联到课时的记录，表示“已提交，尚未做能力评价”。不自动评价作品的艺术性。
- 知识点暂以作者配置的名称关联；没有跨名称同义词推断、前置依赖推断或心理测量评分。统一知识点目录、事件追踪、教师评价和创作目标路线属于后续阶段。

## 部署与验证

1. 保留现有 `.env`、数据库与上传卷，执行 `npm run db:migrate`（0033 新增空知识字段；0034 扩展审计动作）。不用重新 seed。
2. `npm run dev` 会沿用既有启动器自动迁移，启动 API、前端和 worker。
3. `npm run check` 运行 API 类型、安全/业务测试、前端构建与回归、素材及启动脚本测试。
4. 可选：`node scripts/verify-knowledge-bindings-db.mjs`。只允许本地数据库，使用现有演示账号的 ID 创建事务内临时课程和工作流；不登录、不改密码、不调用模型，所有测试写入最终回滚。验证权限、知识点保存、教学设置与进度保留、本人数据隔离和工作流历史版本。
5. 可选：设置 `ARTEDU_PLAYWRIGHT_ROOT` 与 `ARTEDU_BROWSER_PATH` 后执行 `node scripts/verify-knowledge-bindings-ui.mjs`。所有 API 请求都拦截为前端示例，不写真实业务记录；验证后台保存重开、知识状态/作品、推荐精确课时跳转、工作流版本，以及 1440/768/390 像素排版。截图位于被 Git 忽略的 `apps/api/data/qa/knowledge-bindings`。
6. 既有 `scripts/verify-learning-orbits.mjs` 检查圆形布局、分支、键盘、推荐与空用户，覆盖 1440/1280/768/390 像素视口。

## 后续顺序

先由教师选择一条真实课程路线并确认知识点与能力目标，再增加统一目录和学习事件追踪；接着接入教师评价、创作版本回放与个性化目标路线。现阶段的元数据支持后续迁移，不需要图数据库才能使用。
