# 圆形学习图谱

## 页面结构

将 `/my-learning` 默认的知识图谱视图从四阶段表格改成一张横向图谱，保留其他学习视图与现有导航。

顶部不再显示欢迎标题、说明文字和四张汇总卡；直接展示学习图谱，具体进度保留在圆点及详情中。

- 每个阶段有四个圆：学习地图、能力画像、工具轨迹为小圆，成长记录为大圆。
- 保留四个记录圆，并从成长大圆延伸一个浅蓝色学习建议圆；课程→课时/练习→工作流，以及各方面→成长记录均有带说明的关联线。学习建议向后续阶段延伸，形成可继续学习的路线。
- 实线仅用于明确的课程课时包含、课时工作流配置或课程/课时笔记绑定；未绑定的线为虚线建议，不将推测的关系当作事实。
- 四个阶段沿用现有展示目标：认识与启程、方法与探索、创作与应用、融合与表达。
- 板块名称只放在图谱上方的定位注释中（左上学习地图、右上能力画像、下方工具轨迹、中央成长记录），不在圆内重复。
- 圆内显示具体课程、课时主题、任务、工作流和笔记/作品标题；未完成的阶段目标显示待学方向和已完成数量。点击圆点留在图谱内，在下方查看完整记录、已学内容和下一步，以及对应入口。
- 学习证据默认折叠，展开后可回看课程、近期工作流和成长足迹。
- 默认聚焦当前与下一阶段，可选择阶段或展开全部四阶段；窄屏只在图谱容器内横向滚动，不撑宽页面。圆点支持键盘选择和明确焦点边界。
- 点击圆点展开最多三个关联分支：课程展示已配置课时、课时展示教学步骤、笔记展示关联课程/课时。缺失绑定内容时不虚构知识点。
- 点击学习建议圆查看真实未完成数量及推荐理由，直接进入课程/课时、工作流或已有学习视图。`/learning?course=…&lesson=…` 可定位并突出对应已发布课时；快速切换课程时忽略过期响应。

## 数据边界

2026-10-03：已接入课程/课时知识绑定与工作流版本学习配置，新增知识证据区和明确状态文案。详见 [知识图谱业务第一阶段](knowledge-graph-phase-one.md)。下面的早期版本说明描述 10-02 的实现，不代表新增能力已完成正式评价。

学习空间 API 增加只读字段 `learningLessons`：返回当前用户已选且未退课的已发布课程中已发布课时的名称、教师录入的教学步骤、配置的工作流 ID 和本人学习进度。用户 ID 在 SQL 中参数化限定，进度按本人关联；不返回其他用户记录或草稿课时。无数据库迁移。

前端复用 `learningGraphModel.js`；只将进度 100% 的课时标题与教学步骤列为已学内容，在学与待学课时分别标注。缺失课时详情、未配置教学步骤或空记录时不虚构知识点。已加入课程不等于已学习，完成任务/工作流不等于已掌握知识，保存作品不等于已发布。

颜色对应各板块的累计展示目标完成情况，不代表记录发生于特定阶段。大圆颜色仅代表成长记录，阶段百分比汇总四个方面；连线表达学习路径，不表示因果关系或正式能力评定。外部 AI 工具使用记录仍未接入。

## 验证方法

- `npm run check:web`：生产构建、现有前端回归与新增图谱结构及全目标完成测试。
- `npm run check:api` 与 `npm run check:api:test`：API 类型检查、本人课时限定及既有安全回归。
- `node scripts/verify-learning-orbits.mjs`：需本机安装 Playwright，或通过 `ARTEDU_PLAYWRIGHT_ROOT` 指定已有包所在的 node_modules；可通过 `ARTEDU_BROWSER_PATH` 指定浏览器可执行文件。
- 浏览器脚本在 1440、1280、768、390 像素视口检查圆形、不重叠、文字不撑宽、页面无横向溢出、桌面两阶段完整显示、手机完整图谱末阶段可到达。
- 检查全部 16 个记录圆、4 个推荐圆、6 类阶段内连线、关联分支、推荐依据/操作、键盘、笔记与精确课时入口、证据展开、空学习记录及浏览器运行时错误。

浏览器回归采用拦截的前端示例数据，不登录真实账号、不修改学习记录、不调用大模型。截图保存至 `design-qa-assets/learning-orbits/`；这些截图中的进度不是任何真实用户的能力评价。

本轮不改变服务启动方式、账号或数据库。增量内容检查的截图保存到 `design-qa-assets/learning-orbit-content/`；关联网络版本截图保存到 `design-qa-assets/learning-path-network/`。
