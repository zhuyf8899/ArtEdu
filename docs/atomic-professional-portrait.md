# 学习进度专业画像 · 2026-10-29

入口：`/my-learning?view=portrait`；空间总览显示同一组件的摘要。采用用户参考图的深色雷达、浅紫背景和浅色侧栏，不使用参考图里的示例分数、勋章或工具使用次数。

## 当前实现

- 雷达按现有原子的专业方向分类展示。“学习覆盖”和“实践验证”可以切换；方向可以点击筛选下方学习证据。
- 查看范围包括我的原子记录、已加入的原有课程、已发布的原子组合课程。课程目录完整分页读取。时间范围支持全部、近30天更新、近7天更新；这里的日期是记录最近更新时间，不冒充历史事件统计。
- 原子记录显示知识标签、已读/待评价/需修改/已完成状态、实际教师反馈、版本记录和具体版本的跳转。当前已有的原有课程进度另列，67%仍然是2/3课时的进度。
- 下一步建议优先教师要求修改的练习，其次已读未完成内容、可继续的路线原子、等待评价的提交或完整课程入口。建议说明依据，是规则推荐。
- 建议可跳转到具体课程/原子版本，原子及原有课程可加入现有学习计划。请求成功后更新个人空间状态，计划立即可见；防重复点击，失败可重试。组合课程暂不生成现有接口不支持的任务类型。
- 页面聚焦、重新显示以及手动刷新时重新读取原子记录。账户切换时清除显示数据并忽略旧请求；权限错误明确显示，评价或目录可选接口失败不会伪造结果。

## 数据计算

| 范围 | 分母 | 完成覆盖的分子 |
| --- | --- | --- |
| 我的原子学习记录 | 已开始的唯一原子，保留最新已学版本 | 当前统计版本已完成的原子 |
| 所选组合课程 | 固定版本的必修原子，按ID+版本去重 | 相同固定版本已完成的原子 |
| 原有课程 | 已加入课程的课时数 | 已完成课时数 |

实践验证的分母为当前范围的练习原子；分子要求相同原子、相同版本、完成状态，以及已有能力证据中的教师评价人。多个知识绑定不重复计数。阅读、自主完成和教师通过不混为一类；没有教师证据时不会自动称为验证通过。缺少固定版本时暂停比例计算，不用部分记录形成100%。路线先修检查使用未被时间筛选丢弃的精确版本进度。

我的记录不会因目录新增内容而降低比例。未开始方向显示“暂无证据”，有记录但尚未完成显示0%；均不等同于专业能力评分。

## 接口与边界

复用认证接口 `/api/atomic/portrait`、`/api/atomic/abilities`、`/api/atomic/catalog?view=courses`、精确版本详情以及 `/api/me/learning-space/tasks`；沿用现有学习空间提供的旧课程数据。未改接口权限，未写入学习或教师评价记录，无数据库迁移。

当前雷达轴使用已有方向分类。参考图中图像生成、视觉叙事等八维能力，需要后续课程作者建立明确的能力标签、练习量表和评价证据；当前不凭标题或工具点击推测分数。模态使用、兴趣、勋章和按时点对比也不填示例数据，等对应真实记录与规则具备后扩展。
