# 节点画布统一与修复报告（2026-10-25）

后续已完成平台 API 真实模型与页面验收，见 [真实执行验收报告](workflow-live-verification-20261025.md)。GPU 检查确认 Local Bridge 未注册且启动命令停用，不能仅凭已有 ComfyService 源码和模拟 Worker 推断 GPU 链路已可用；下文保留当时隔离测试的范围。

## 交付结果

平台 API 图与 ComfyUI 图现在使用同一个 `WorkflowCanvas`、同一套 ReactFlow 编辑交互、工具栏、分组、自动整理和侧栏。`ComfyCanvas` 只保留兼容入口，内部直接调用统一编辑器，不再维护第二套编辑状态和画布实现。ComfyUI 节点保留独立的参数渲染器；平台 API 与 GPU Worker 仍按各自的真实执行协议运行，不将 GPU 参数虚构为云端 API 能力。

| 原问题 | 实现与验收 |

| 普通添加、单节点复制缺少数量预检 | 添加、复制、粘贴、模板插入及统一提交入口均检查 80 节点、160 连线、20 分组；浏览器实际验证第 81 个节点被阻止。保存和导入继续校验。 |

| 分组边框包不住高节点 | 使用成员节点实测尺寸；浏览器验证分组覆盖完整循环节点。 |
| 节点重新渲染后不可见 | 保留受控节点测量结果；修复尺寸丢失引起的 `visibility:hidden`，在自动整理和视角变更后保持可见。 |
| 历史只显示最近 20 条 | 保留接口返回的全部记录，每批展开 20 条；浏览器验证第 21—25 条可见，Docker 数据库验证超过 20 条记录可读。 |
| ComfyUI 执行停用却仍展示运行区域 | 统一编辑器显示 Worker 连接状态；在线且已配对时可保存并试运行、发布，显示真实任务进度与产物，支持取消与失败重试；离线可编辑与导出，运行入口明确等待 Worker。 |
| 字体偏小、连线不清楚 | 提高节点标题与参数字号、连线亮度和宽度，限制首屏最大缩放，整理循环参数表单；保留全图、缩放和移动端适配。 |
| 条件分支不支持 | 新增条件节点，支持文字、正负提示词与错误信息的包含、等于和非空判断；仅激活 true/false 一路，其余分支记录为跳过。 |
| 循环不支持 | 新增有界循环节点，支持文字模板、精确替换、文字生成；1—20 次，每轮使用上一轮结果，可按停止文字提前退出；保存实际轮数和每轮输出。 |
| 失败分支不支持 | 平台节点提供 error 输出。执行失败时记录错误并将其作为文字传给处理分支，正常输出分支跳过；没有错误处理连线时保留原有报错语义。 |
| 节点重跑不支持 | 新增本人运行快照的重跑接口与历史详情按钮，清除目标节点及下游结果，保留其他有效结果，重跑过程不重复调用无关节点；拒绝越权、过期、未来节点和执行中的运行。 |
| 结果选择仍执行两路模型 | 从终点反向计算必需节点，忽略未选输入；无其他用途的分支不执行。共用祖先和流向其他终点的分支仍保留。Docker 验证原先两个生图分支只调用所选模型一次。 |
| 旧报告的目录分页问题 | 当前原有目录和管理页均已有“加载更多”，保持该能力并通过既有回归。 |

未选择的图片输入、空需求节点也会自动跳过，不要求用户为已跳过的分支上传素材。临时工作流执行同样采用分支路由、结果选择和失败处理规则；循环内调用前检查取消信号。

## 使用方式

- 条件：节点库添加“条件分支”，选择字段与运算符，将“条件满足”“条件不满足”连接至对应处理链。分支汇合可连接到预览；文本拼接仍需要 A/B 两路真实数据。
- 循环：添加“有界循环”，接入上游文字，选择操作与次数。模板使用 `{text}` 和可选 `{index}`；文字生成操作每轮都会产生一次模型调用。
- 失败处理：把需要容错节点的“失败时”端口接到文字处理或预览链，错误信息作为上游文字。
- 重跑：打开“历史”→“查看结果”→“从此节点重跑”。使用原运行版本，画布尚未保存的修改不会进入旧任务。
- ComfyUI：导入原有 JSON/PNG 后仍在统一画布内编辑。连接本人已配对且在线的 GPU Worker 后刷新 Worker 状态，即可使用运行、发布及结果展示。离线支持 UI 0.4、UI 1.0、API JSON 和平台备份导出。

## 仍须明确的边界

- 当前 Docker 中只有 PostgreSQL。数据库集成是真的；模型调用使用隔离桩，Worker 在线及 GPU 完成状态使用浏览器模拟。未宣称完成真实供应商或物理 GPU 生图验收。
- 本次循环是有上限的文字处理/文字生成循环，不是任意节点子图循环。任意回环连线仍拒绝，防止无法终止的执行。
- 原生 ComfyUI 图可以在已有 GPU Worker 后端上运行；没有在线 Worker 时无法执行 GPU 节点。平台 API 引擎中的 LoRA、ControlNet、VAE 等未接入运算的旧节点仍拒绝发布，不会被静默当作已支持。
- ComfyUI 的节点级重跑仍交给 ComfyUI 本身的缓存/执行机制；新增“从此节点重跑”针对平台 API 工作流。
- 80 节点、160 连线、20 分组以及 20 分钟运行上下文保留策略保持有效；本次修复的是越界前缺少提示和历史入口，未移除资源约束。

因此，本次完成了统一编辑器和逐项可用的修复，但不等于消除了所有通用工作流引擎或 GPU 环境限制。
