# 统一课程与原子学习入口

依据用户 2026-10-29 两张截图及已确认的整合方案，保留 MORPH 视觉语言，修改已有前端；未创建新的独立站点。

## 页面组织

- 主导航收敛为“完整课程 / 学习原子”，右侧提供“我的学习”和按角色展示的贡献、上传、编排、审核、练习评价入口。
- `/learning?library=courses` 汇总原有课程和原子编排课程。旧 `library=legacy` 列表地址进入相同目录；原 `?course=` 课时详情及进度仍由原服务处理。
- 课程目录按资源 ID 和版本区分，不按标题去重或继承完成度。现有 13 门课程目录及 1 门交接组合课程分别呈现，徽标区分试学、知识大纲和筹备。
- 课程分类数量依据当前开放状态、搜索和学习状态计算；课程用“门”，学习原子用“个”。筹备内容仍不能选课。
- 原子卡片直接打开其自身的指定版本详情；“被哪些课程采用”使用原有真实关系，课程返回保持来源。旧课增加“查找相关原子”，明确是关键词检索，不制造课程依赖。
- 课程网络默认收起。展开保留原始图形和资源选择对话，修正网络容器高度，避免侧边组合按钮被裁切。“AI 辅助组合我的课程”改为“组合学习路线”。
- 缩小页头、统一卡片尺寸和封面、主次按钮、状态徽标、字号与筛选；去掉连续堆叠的旧目录说明区。

## 实现位置

- `morph/UnifiedCourseCatalog.jsx`：统一课程数据读取、分页、开放状态、搜索和分类。
- `morph/learningCatalogModel.js`：身份、真实进度、成熟度标注和筛选计数。
- `morph/learning-catalog.css`：共享导航、收起的网络区和卡片样式。
- `AtomicLearningHub.jsx`、`Portal.jsx`：入口兼容与工作区联通。
- `LearningLibrary.jsx`、`resourceContext.js`、`HandoffSeriesView.jsx`：详情、上下文回链和异常状态。
