# SSO 接入前的教学文件访问方案

在学校 SSO 可用前，平台只允许在受控测试或校内联调环境启用本地账号。该账号体系不是匿名访问的替代方案，也不得用于公网正式发布。

## 当前规则

- 管理员通过后台管理账号状态；教师只可上传和管理自己创建课程的资料。
- 所有教学文件保存在 `UPLOAD_ROOT` 私有目录，Web/Nginx 不得把该目录映射为静态站点。
- 学生需先加入已发布课程，才可通过 API 预览该课程的课件（视频、PDF、图片、网页课件、Office 原件等）。
- 课件类型包括视频（MP4/WebM）、PDF、Word、PPT、图片（JPEG/PNG/WebP/GIF/SVG/AVIF/BMP）与前端界面（HTML/CSS/JS）。
  预览按类型呈现：视频用播放器、图片直接显示、PDF 与单文件 HTML 内嵌在课程页。
- 下载策略：**视频与单文件网页课件只提供在线预览，学生端不提供原件下载**；PDF、图片与 Office 原件可以下载作为备选
  （Office 原件浏览器无法内嵌渲染，下载后用本机 PowerPoint / WPS 打开）；CSS/JS 源码无法单独渲染，保留下载。
  下载地址由受控 API 现场签发，不是可直接转发的公开地址。
- 课件内容的版权与合规责任由上传的课程创建教师承担，平台按账号、资源、时间和方式记录每次预览、播放与下载，便于追溯。
- 每次受控播放或下载均记录资源、账号、方式和时间，便于后续追溯。
- 本地账号会话使用 HttpOnly、SameSite=Lax Cookie；必须保持登录限流与账号停用能力启用。

## 上线边界

校内测试环境仍应使用 HTTPS、固定 CORS 来源、私有存储路径和定期备份。staging 容器默认只绑定 `127.0.0.1`，应经 SSH 隧道、校园 VPN 或学校 HTTPS 反向代理访问；若要改为 `0.0.0.0`，必须先完成网络评审并同步修改 `ARTEDU_CORS_ORIGIN`。学校 SSO/OIDC 到位后，只替换认证来源；课程、资源、访问审计和文件存储键无需迁移。
