# 我的学习图谱与卡片分区完善

## 本轮范围

- 我的学习增加四阶段、四方面的统一学习框架：学习地图、能力画像、工具轨迹、成长记录。
- 学习首页、我的课程、学习计划、学习笔记、收藏案例、我的作品共用横向导航；手机端可横向滚动导航。
- 我的课程、AI 讲堂、设计工具、案例社区统一增加轻量外框、柔和阴影、封面分隔、操作区分区和键盘焦点提示。
- 我的课程状态使用现有课程进度显示“已完成 / 进行中 / 未开始”，不新增虚构数据。
- 工具图标尺寸与网格列宽保持一致，避免图标和说明分隔线重叠。

## 数据与边界

本次是现有学习接口上的前端呈现，不修改数据库结构或 API 合约。图谱使用用户已有课程、课时、任务、笔记、作品和近期工作流记录；推荐入口附有依据说明。

四阶段颜色为可观察记录的展示目标完成情况。“熟练”不代表正式能力认证，外部 AI 工具的实际使用情况尚未接入。管理员知识点配置和完整能力评估不在本次实现范围内。

## 验证

- `npm run check:web`：生产构建及 78 项前端回归测试通过。
- 浏览器检查 1280px 桌面和 390px 手机视口：四个模块无页面横向溢出，卡片边界可见。
- 我的课程桌面三列等高、手机单列；键盘选中有外框，课程状态与真实进度一致。
- 本地浏览器检查期间未发现控制台错误；案例社区现有 10 张卡片可正常展示。

## 部署

使用现有依赖安装和构建流程，无新依赖和数据迁移。不要提交本地 `.env`、密钥或环境个性化配置；本次发布不包含 `apps/api/.env.example` 的本地无关改动。
