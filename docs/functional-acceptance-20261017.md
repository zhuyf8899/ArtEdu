## 问题与优先级

### 已修复的本地环境问题

课程详情首次500，API明确报 `column l.teaching_json does not exist`。先将现有数据库备份至 `local-artifacts/qa-before-migrate-20261017.dump`，再执行 `npm run db:migrate`，新增应用 `0037_morph_content_catalog.sql`，复测详情、选课、进度通过。没有执行 catalog:install 或归档旧内容。目标服务器也需独立核对迁移状态。

### P1：Agent失败被当作成功展示

网络受限时，站内查询的助手回复是“生成未完成：fetch failed”，但同时弹出“已完成 Agent 创作”，并出现建议追问。Portal.jsx 的流式完成分支尚需校验完成状态，不能仅因SSE结束就显示成功。故障触发来自环境，但错误反馈逻辑的问题实际存在。

### P1：PPT页数要求未兑现

用户输入“只有一页”，实际下载文件 `artedu-ce756d90.pptx` 有2个slide XML：第一页为封面与额外说明，第二页才是标题、正文及平台页脚。生成下载链路通过，内容约束失败。需要统一自然语言页数、界面页数参数和导出器封面计数。

### P1：中断恢复可能遗留等待占位

联网生成时测试标签页意外消失，重新打开会话后旧回复仍写“正在用DeepSeek Flash处理……”，但界面无生成状态和暂停按钮；新一轮可正常发送。应在恢复时把遗留streaming占位转成中断状态，或基于服务端任务状态恢复；不应长期显示等待文案。此场景为浏览器标签页中断，未归因于模型本身。

### P1：新版内容目录未安装

本地实测为15门旧课程、8个工具；新版目录安装器尚未执行。课程体系点击“海报设计”返回0门课程并禁用保存。该问题涉及内容发布，未为通过测试而直接安装/归档目录。需先确认内容发布范围，再安装新版目录并复测路径。

### P1：精选模块为空

案例社区14个案例全部在社区模块，精选艺术案例为0。界面分区存在，内容配置未达到会议要求；不把案例总数当作精选数量。

### P2：前端适配仍有边界

个人资料/封面仍无编辑入口；工具推荐仅保存浏览器；课程体系为规则推荐；课程与工具收藏、Remix尚未在React主界面形成闭环。首次课程页加载短暂显示本地演示模型/空会话，稍后恢复真实配置和历史，属于加载状态待改善，不是历史永久丢失。
