# 统一平台模型与20分钟云端缓存

2026-10-18：按用户要求取消自行配置模型和本地Bridge，统一使用平台已有模型。

## 当前行为

- 应用不再注册LocalBridgeModule，旧配对、心跳、领取任务、结果回传和本地GPU Worker接口不可用；后台导航及API调用入口移除。旧CLI运行入口也会提示停用。
- Agent执行默认server，拒绝local。前端平台服务不可用时明确报错，不再回退成本地模拟成果。模型选项来自平台配置；不接收用户上传模型密钥。
- 浏览器IndexedDB仍保存本机对话。发起新请求时才上传该分支必要的对话、附件引用与执行参数。
- 云端Agent请求、消息、工具参数/结果、摘要及扫描记录按创建时间20分钟过期。过期读取立即被拒绝，后台删除主记录并级联删除内容。
- 附件固定上传后20分钟过期，读取不会续期。旧72小时配置已移除，旧记录也按创建时间20分钟钳制。过期文件与元数据会清理。
- 工作区文件、未保存的生成文件按文件写入时间20分钟过期。工作区读取、预览与检查拒绝过期文件；过期生成文件下载同样被拒绝。
- 生成任务的用户prompt、parameters、错误正文，以及工作流上下文、事件备注、旧Comfy任务正文到期清空；只保留不含对话正文的状态/计量元数据。
- 已关联作品或学习成果的生成文件明确受到保护；账号、课程、已发布作品和用户主动保存的学习成果不属于临时缓存。工作区源码与临时成果应在20分钟内下载。
- 清理在服务启动时执行，随后每30秒执行；逻辑过期先于物理清理。大量历史记录或清理故障可能使物理删除延后，会持续重试；不是毫秒级安全擦除承诺。

## 实现

- apps/api/src/modules/cloud-cache/cache-policy.ts：20分钟常量和边界判断。
- apps/api/src/modules/cloud-cache/cloud-cache.service.ts：正文清理、数据库级联删除、受控目录文件清理及已保存产物保护。跳过符号链接，只清理temporary/agent-runs/agent-workspaces/generated四个托管子树。
- creation-storage.service.ts：固定附件到期，不续期，过期清理文件和元数据。
- agent.service.ts、agent-workspace.service.ts、generation.service.ts：读取时校验到期。
- agent-harness.service.ts：执行信号受剩余缓存时间限制。
- app.module.ts、agent.contracts.ts、AdminDashboard.jsx、navigationModel.js：移除Bridge入口，默认云端模式。

## 验证

后端179项、前端187项、既有11例业务回归通过；真实本地PostgreSQL事务验证19分钟保留、21分钟删除、消息级联删除、账号保留，以及所有清理SQL的有效性，最终全部回滚；托管文件测试验证过期文件删除、新文件保留、已保存文件和发布目录不受影响。前后端构建通过。未调用外部模型API。

## 部署边界

本次修改在本地工作区，尚未部署远端服务器。不需要新增数据库迁移；更新服务启动后会执行新清理规则，也会处理已过期的历史临时数据。

20分钟规则针对平台在线数据和临时文件。历史备份、数据库WAL/快照，以及第三方模型服务自身的数据保留不由这段应用清理代码控制，不能据此宣称所有介质中的历史副本都在20分钟内消失。
