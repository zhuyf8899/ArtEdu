# Agent 输出与逻辑：本地沙箱实验

日期：2026-10-18。未修改生产业务源码和线上服务；只新增实验模块，并扩展之前审查驱动的测试注入接口。

## 已实现

在当前真实 Harness 的隔离副本中接入候选提示词组合、任务合同、模型/工具循环、交付判定和输出视图。平台工具仍复用现有实现，文件与数据库为内存替身。

| 场景 | 原链路可见问题 | 本轮候选行为 |
| --- | --- | --- |
| 说网页完成但没有文件 | 可以 succeeded | failed，明确缺交付物 |
| 写了网页但没检查 | 可以 succeeded | partial，文件列为待验证 |
| 网页检查 fail | 工具仍显成功，整轮可 succeeded | validation_failed，整轮 partial |
| 检查后又改坏文件 | 没有完成门槛 | 原检查作废，要求重查 |
| 文件已验证、调用预算耗尽 | 整轮 failed，成果不明显 | partial，保留可打开的有效成果 |
| 工具要求用户确认 | 可显示工具成功 | needs_confirmation，等待动作确认 |
| 输出/工具参数截断 | 可能继续执行或假成功 | 不执行该截断批次，明确标记未完成 |
| 只要求讨论，模型却试图写文件 | 仍提供写操作 | 工具列表与执行层双重阻止写入 |
| 多产物只完成一项 | 先选一个通道，容易漏任务 | 合同保留所有要求，缺项不得成功 |
| 上下文被重试截断 | 模型仍收到被丢弃分支 | 从同一可见分支构建上下文 |
| 最终回复只有裸路径 | 用户没有可点链接 | 根据工具结果生成独立成果卡片 |
| 模型/工具状态被隐藏或折叠 | 看不出进行中、暂停或等待 | 明确阶段、状态及开始/结束记录 |

补充尝试：保留压缩记忆和产物状态的独立预算；文档生成继承讨论的文本内容；静态检查补查空 style、CSS 外链、经典脚本语法错误及离线环境禁止的网络请求。

## 验证结果

- 57/57 项离线检查通过。
- 真实候选循环接入真实 Harness 副本和真实平台工具函数；模型响应序列、数据库、文件服务使用测试替身，不是对另一个简化业务实现自测。
- 先前 8 组真实模型结果完成回放：已有文件和 pass 记录的预算失败任务变为 partial 并保留入口；两个裸路径成功结果获得结构化打开链接；没有文件的任务仍为 failed。
- 16 个对照场景的实验页面启动与切换检查通过。
- 实验 runtime/tools 通过 TypeScript 严格检查（允许导入 JS 策略，JS 未启用 checkJs）。
- 测试前后比对 5 个相关业务文件 SHA-256，保持一致；初始阶段未新增外部调用；后续已完整执行 11 项真实 API 测试，消耗 36 次文本、1 次图片调用，详见 agent-sandbox-eleven-live-20261018.md。

输出：`local-artifacts/agent-sandbox-20261018/index.html`、`results.json`、`real-output-replay.json`、`preview-check.json`。

## 结论边界

这些结果证明候选编排、验收和呈现能在已覆盖输入下修复对应行为，不证明真实模型的任务成功率已经提高。任务判断仍是启发式；静态检查不能代替浏览器视觉和交互验收；会话、数据库、生产状态枚举、授权记录和旧前端入口尚未合入候选实现。

实验实现及可复运行命令见 `apps/api/scripts/agent-sandbox/README.md`。先查看对照产物，再决定合入哪些逻辑。
