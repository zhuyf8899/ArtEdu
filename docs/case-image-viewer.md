# 案例图片适屏查看（2026-10-12）

旧社区图片浮层位于带 `transform` 的页面动画容器内，`position:fixed` 实际按长页面而非浏览器视口定位。图片打开后看似消失、需要滚动数屏才能看到，并非图片丢失。

- 案例详情复用 `ImageLightbox` 的 `document.body` Portal，适屏显示原比例图片；画面、上一张/下一张、缩放、原图及关闭操作留在当前窗口内。
- 图片查看支持键盘左右键、Esc、滚轮缩放、拖动平移；切图复位缩放，关闭恢复焦点及原来的滚动位置。Tab 不进入背后页面。
- 案例封面高度限制为约38%视口、最多360px。按用户两张参考图，案例及课程资料图集统一三列、24px间隔、4:3比例、6px圆角；小屏两列、12px间隔。缩略图作居中裁切，点击后完整原比例显示，不修改或重编码原文件。
- 图片、原作者、来源、审核状态及原文件均不修改。大图使用 `object-fit:contain`，深色遮罩、右上关闭、两侧切换和底部轻量操作栏，不展示文件名。
- 同一个深色看图组件供案例、课程图片、AI对话、工作流、图片画布和 Comfy 图片结果使用。审核正文也支持点击看图。
- 案例图集、视频附件与课程媒体去掉文件名/媒体标题，图片画布去掉生成文件名。作品标题、作者、课程名称、文档附件名称、上传选材/审核文件列表不删除，原图下载仍带正确文件名。
- 视频播放器、下载权限、作品来源及原作链接保留；不上传、不删数据库资源，也不改作者作品介绍。

验证：`npm run check:web`；手动页面回归 `scripts/verify-case-image-viewer-ui.mjs` 需要已有 Playwright、Edge、本地服务及演示密码环境变量。脚本只创建登录会话，不上传、审核或点赞；检查桌面、平板、手机、横屏长页面中的定位、导航、焦点与滚动恢复。
