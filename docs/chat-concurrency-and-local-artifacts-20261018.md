# 聊天并发与本机成果保存（2026-10-18）

## 修复

- 同一账号可在一个聊天生成期间开启另一聊天。执行中的消息、流式缓冲、暂停句柄和文件写入队列按会话隔离。切换会话后，旧任务的增量、完成、异常和建议提问不能覆盖当前消息区。
- 同一会话不重复启动任务；暂停只影响当前会话。运行中的会话不能直接删除。
- 网页工作区按本地会话 ID 分目录，同一用户的两个任务写 `index.html` 不会相互覆盖。
- “生成前端界面”“创建个人博客”“设计一个 UI 界面”识别为网页交付；效果图仍走图片流程，讨论仍走文本回答。线上原始博客请求此前被识别为普通问答，内联代码被截断。
- 云端 Agent 不再默认设置 3600 输出 token 或八轮执行预算，也不接受前端 callBudget 限制。供应商自身限制、用户暂停和现有二十分钟执行期限保留。普通文本达到供应商输出长度后继续生成并合并回答；截断的工具参数不执行，而是要求完整重试。

## 本机文件

成果生成后自动将文件字节写入与聊天同一 IndexedDB 的 `conversation-artifacts` 存储，而不是只保存云端下载地址。网页同时快照样式、脚本和图片，并生成可离线查看、下载的 HTML；预览在不允许同源权限的 iframe 沙箱内运行。

每条回复关联不可变的成果快照；会话的 `savedArtifacts` 独立保留文件索引，不因历史消息压缩而删除。删除会话时同一事务删除对应成果。暂停时能获取到的已生成成果也会尝试保存。本地空间不足或资源保存失败会显示失败状态，不能标为保存成功。

本机成果没有时间过期规则，云端二十分钟清理不影响已落地副本。数据属于当前浏览器及站点，不是系统文件夹；更换浏览器、清除站点数据或浏览器回收存储仍可能使它不可用。请求浏览器持久存储，并提供显式文件下载。此前已经过期且未保存的云端成果无法凭聊天链接恢复。

## 验证

- 后端 183 项安全及业务测试通过，包含原始博客请求、十二轮任务、长文本续写，以及同用户不同会话实际写入同名文件的隔离测试。
- 前端 43 项对话测试与 130 项平台测试通过。
- 隔离浏览器实际验证：两个对话并发、旧增量不串入空白新会话、旧完成/失败不覆盖当前任务、暂停独立、刷新后云端资源返回 410 仍能预览本机网页及图片样式并操作按钮、沙箱不能读取父页、删除聊天同步删除成果。
- 前后端类型检查及前端生产构建通过。未用真实供应商重新生成网页，未部署这些修改到服务器。
