## 页面与业务衔接

- `/learning` 默认展示学习原子库；原有试学课程和历史进度仍可从“课程库”进入，原来的 `?course=` 链接继续有效。
- 使用参考页的浅紫底、粒子网络页头、课程知识网络、分类计数、双列横向封面卡片与详情弹窗。参考封面资源保存在 `admin-console/public/morph-course-network/`，不依赖外链图片。
- 网络读取 `/api/atomic/network`；节点分别对应已发布课程、教师原子和已审核心得。课程采用、显式先修和心得关联来自数据库，不按标题猜测关系。
- 每个节点包含明确版本。课程仍引用原定原子版本；图谱包含课程引用的历史公开版本及最新公开版本。切换课程可聚焦对应主线；节点跳转保持版本。
- 搜索、分类、学习状态在服务端筛选后分页。分类计数统计当前可见、匹配搜索的全部记录，不限于当前页，也不暴露其他人的草稿。
- 卡片使用实际阅读、提交、评价、完成状态。课程进度按必修原子和独立课程任务计算；不复制参考站示例的百分比或作者。
- 上传心得、选择已发布源原子、多附件、失败重试、版本保存、教师/管理员审核、练习评价、附件授权预览继续沿用既有接口与权限。
- 正文学习详情、原子上传、心得上传与课程编排保留业务内容，统一外层导航、按钮、留白和配色。

- `npm --prefix admin-console run test:platform`：145 项通过。
- `npm --prefix apps/api run test:security`：254 项通过。
- 前后端构建通过。既有 PPTX 预览器的大文件分包提示仍存在，不影响构建。
- Chrome/Playwright 固定 1280×900 桌面视口：分类和空结果、状态筛选、搜索、详情 Esc、图谱跳转、教师附件入口、学生源原子选择和心得附件入口通过；页面异常为 0。另检查 1440、1920 宽度，无页面横向溢出。

## 有意保留的差异

参考页为设计样例；本地显示真实已发布内容，因此课程数量、知识关系、贡献者和学习状态不同。现有多角色功能需要保留课程库、学习记录、贡献、审核和评价导航。图谱可拖动、缩放，并使用真实关系动态绘制，不能用参考图中的示例关系或作者替代。

当前仅作本地集成，未提交或合并 GitHub，也未部署腾讯云。无数据库迁移或内容重置。
