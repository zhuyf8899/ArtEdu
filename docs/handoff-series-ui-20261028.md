# 交接系列课程页面补全

本轮补齐此前仅同步目录与数据、未还原系列详情页的缺口。来源：用户截图及 MORPH LAB `/infographic-design`。

原始课程介绍、主讲信息、10次课安排、19处课程节点（17个唯一原子）及34处下级内容保存在白名单 React 元素树中，保留原稿字体、底色、圆角、虚线连接、课次位置与5件原始 SVG 素材。没有执行交接站脚本或注入 HTML。宽屏保留原始1536坐标，较窄桌面等比缩放，不产生页面横向溢出。

教学安排、教学团队、节点与讲授者搜索、展开/收起均已接通。课程节点新增“学习本原子”操作，进入原有正文、进度、心得及附件页面；返回后回到系列课程。底部保留实际课程学习主线、专属任务及管理员编辑入口。已发布版本1使用原稿展示，后续编辑草稿及其他版本沿用真实版本编辑与展示流程。

交接站实际仅提供一个系列详情页面；目录中属于该系列的原子会进入此页，其他独立原子保留自身内容，未将不同课程伪装成同一门课。原稿已提供的全部页面节点被保留，尚未提供的正式讲义及视频仍维持资料状态。

浏览器组件核对：1440×1000，10次课、19个节点、34处下级内容；展开后19个节点打开，搜索CNN仅显示1个匹配课次，教学安排与教学团队弹窗、Esc关闭和原子跳转通过；页面异常0、无横向溢出。源站与本地截图和核对记录保存在本次本机QA目录。前端构建与云端构建通过，云端新入口与5个SVG素材校验通过。仅重建前端，API与学习数据库未更改。
