# ArtEdu 安全基线

## 当前已实施

- 生产环境禁止开发身份认证；前端生产构建默认禁用演示身份切换。
- 精确校验 CORS Origin，限制请求体为 1 MiB，并设置基础响应安全头。
- API 使用本地速率限制作为单实例安全阀；写请求每 IP 每分钟 30 次，读请求 120 次。
- 课程、工作流、工具、搜索和作品接口均要求登录；课程、作品、评论与互动只允许访问已发布内容，作者和授权审核角色例外。
- 平台额度与账号停用只允许 `admin`；运营不可通过通用生成任务接口读取他人提示词。
- 未接入模型执行器时拒绝创建生成任务，worker 不会领取任务。
- 开发身份认证只允许绑定本机回环地址，且每个请求必须显式提供测试身份；对象存储键、文件名、MIME 类型和外部链接均在入库前校验。
- 对话、学习进度和作品引用只能关联已发布的课程或工作流。
- 生产依赖通过 `npm audit --omit=dev` 检查。
- CI 执行输入验证与环境配置的安全回归测试。
- API 使用全局鉴权守卫：新接口默认要求登录，匿名接口必须显式标记；错误响应统一返回请求追踪 ID，且不会泄露内部异常信息。
- 请求使用随机追踪 ID；应用收到关闭信号时会停止接收新请求并关闭数据库连接池。

## 上线前仍必须完成

- 用学校 SSO/OIDC 替代开发用 `x-user-id`；不可在生产环境配置 `ENABLE_DEVELOPMENT_AUTH=true`。
- 使用学校密钥管理服务管理数据库、模型和对象存储凭据；禁止沿用 Docker 本地示例密码。
- 接入对象存储后，上传接口必须签发受限上传凭据、校验 MIME/大小并进行恶意文件与内容审核。
- 接入模型服务后，使用共享速率限制（网关或 Redis）、最小权限模型策略、审计与输出内容审核。
- 在负载均衡或反向代理环境中，显式配置可信代理地址后再依赖客户端 IP 限流。
- 为授权边界、内容发布状态、上传和模型任务补充集成测试，并在 CI 中执行依赖审计。
