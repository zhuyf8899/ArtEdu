## 本轮修改

- 原子课程：恢复 AI 编排课程体系入口、交接包状态标签与双按钮卡片；精简额外筛选、课时/方法文字和冗余元信息。
- 课程编排：新增 `/curriculum`，按目录中的真实课程 ID 提供三个方向的建议路径，支持刷新恢复、课程跳转和保存到个人学习笔记。
- 技能工具：恢复推荐入口及工具推荐表单，支持当前账号在当前浏览器中保存、回填草稿；关闭及 Esc 返回入口焦点。
- 保留真实试学/筹备状态和学习进度，不导入演示教师、浏览量、收藏量或完成记录。

## 实现边界

课程编排目前是交接包预设方向与当前目录匹配，未接入生成模型，不产生付费调用，也不自动选课或更新掌握度。保存路径通过既有个人笔记接口完成。

工具推荐目前是本地草稿，未提交管理员审核或公开发布，不绕过工具目录的管理权限。现有 22 个真实工具条目及工作流功能保持不变。

本目录只发布上述最终界面证据。中间截图、个人学习笔记截图、本地日志、数据库备份、上传文件和环境配置均不纳入本次提交。
