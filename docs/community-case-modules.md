# 案例社区双模块（2026-10-12）

案例社区同时呈现“精选艺术案例”和“社区案例”。统一搜索、作者及分类标签筛选会影响两个模块，分别显示匹配数量及空状态；页首入口可直接定位各模块。

- 精选区当前为 CVPR 的 Reflections on Mechanical Creativity，保留原作者、官方来源及原作链接。仅一件作品时，桌面采用横向展品卡，手机上下排列，避免留下大面积空网格。
- 社区区保留其他10个已发布案例，桌面沿用三列一致卡片。
- 没有模块标记的旧案例默认社区，不按标题、外部来源、点赞或既有首页推荐标记推断精选身份。

## 数据和权限

`story_json.collection` 为 `community` 或 `art-selection`；读取时兼容旧数据，不新增数据库迁移。列表和详情API都提供 `collection`。

管理员及运营可通过 `PATCH /api/admin/works/:workId/collection` 调整已发布作品，社区详情仅向这些角色显示归属控件。操作只修改归属字段并追加审计，不修改作者文字、状态、媒体或私有备注；重复设为同一模块不产生重复审计。

普通投稿契约不接受模块字段，表单也不提交该字段。新作品默认社区，编辑作者内容会保留服务器上的原归属，不能自行设为精选或清空策展信息。教师可按既有权限审核，但不自动获得精选策展权。

本地已按平台所有者请求将指定CVPR作品移到精选区；四个测试账号均验证为精选1件、社区10件。普通学生/教师修改归属返回403，普通投稿伪造精选字段返回400，未创建测试作品。

## 验证与部署边界

- 完整 `npm run check`：类型、权限契约、模块分组、旧案例兼容、导入工具、构建和回归。
- `scripts/verify-community-modules-ui.mjs`：桌面、平板、手机；完整加载封面后截图；不溢出、不重叠；搜索、标签、空结果清除、模块定位、详情返回、刷新及管理控件。
- 只新增业务代码与本地归属，不公开提交CVPR图片或数据库。代码更新不会自动同步本地作品记录到其他部署。
