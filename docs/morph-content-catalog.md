# MORPH 原子课程与技能工具内容部署

## 交付范围

- 交接包 `platform-data.js` 中 13 门课程目录与 19 个工具，稳定业务 ID 和原始 legacy ID 映射。
- 设计基础 7 门、设计方法 4 门、软件实操 2 门。全部封面复用已入库的公开前端素材。
- 色彩构成基础（45 分钟）、字体认知（30 分钟）、版式网格入门（60 分钟）各 3 个试学课时：知识讲解、观察示例、步骤、练习、完成标准与最终本人作品关联。
- 试学讲义为本轮新编、待教研审核，不是交接包原讲义或已审核课程。作者待确认；完成记录只是自主练习记录，不是专业能力认证。另 10 门仅展示筹备规划，服务端拒绝选课，不展示虚构视频/讲义/进度。
- 19 个第三方工具仅提供官网导航、用途、类别及关联课程，不宣称 API 接入、免费或全球可用。5 个站点的读取未成功，显示“访问验证待确认”，不将抓取失败等同于网站失效。参考地址来自交接包及官方网站；Codex 指向 <https://openai.com/codex/>，核对日期 2026-10-16。
- AI 创作助手、数字皮影实验室及节点工作流入口继续保留，故目录总数为 22。工作流业务和案例社区保持不变。
- 首页、搜索、课程详情、工具关联和个人课程使用同一服务端内容来源。我的课程保留旧课程历史筛选；新课不会继承旧课进度。

## 已审批的旧内容范围

只归档 `course-ai-design-foundation`、`course-traditional-pattern`、`course-vibe-gallery`，以及旧 Figma / Canva / Photopea / Behance / Unsplash 目录条目。新 Figma / Behance 条目使用新目录 ID。不会删除课程、课时、资料或学习记录，也不会改变案例、模型配置、额度、密码或审核决定。

旧链接显示“课程已下架，历史学习记录与笔记仍然保留”，并提供新课程入口。已有课程仍在个人历史中显示，不能继续写入下架课进度。旧笔记和作品关联保留；历史待办不自动完成或改为新课程。

## 部署

正常构建不需要桌面的原始 ZIP，也不执行包内业务脚本。`manifest.json` 和公开封面均已位于仓库内。

```sh
npm run db:migrate
npm run catalog:verify   # 内容、数量、引用及封面校验，不连接数据库
npm run catalog:plan     # 只读预览新增与指定归档清单
npm run catalog:install  # 显式安装；先备份，再执行事务
```

首次演示环境可沿用 `npm run db:prepare`，它在原来的迁移/演示 seed/案例安装之后安装该包。不要在现有环境为替换目录而清库或重新 seed。`scripts/start-local.ps1`、`deploy/deploy-staging.sh` 也在迁移后调用相同安装器。服务器部署仍先执行原有的数据库及上传文件完整备份。API 镜像包含封面校验所需的公开素材；网页镜像负责展示这些文件。

## 安全与版本

安装器默认 `--plan`。真正安装前必须成功写入本地内容快照 `apps/api/data/catalog-backups/`；写失败则不修改目录。快照同时存入 `content_bundle_installs` 数据库日志（服务器一次性容器中的文件可能临时存在，数据库日志及原有部署完整备份用于持久恢复）。快照包含受影响内容元数据，不导出个人笔记、密码或会话。

数据库事务锁防止同时安装；同版本同内容重复安装无写入，不覆盖管理员修改。相同业务 ID 无安装日志时拒绝覆盖；相同版本的清单发生变化时拒绝覆盖，后续内容更新必须创建新版本及迁移计划。SVG 校验统一换行，PNG 校验原始字节，兼容 Windows/Linux。

课程目录上架状态与教学成熟度分开：`courses.status=published` 表示目录可见；`catalog_json.availability=trial/coming_soon` 和 `reviewStatus=pending` 明确表示试学/筹备及教研状态。没有创建“已审核通过”的课程审核记录。后台显示“试学·教研待审/目录·筹备中”并提供预览。不要把目录上架当成正式课程审核完成。

## 回退

```sh
npm run catalog:rollback
```

通过数据库安装快照恢复指定旧条目的状态，并把新条目归档；不删除新课期间产生的学习记录。若发现安装后课程、课时或工具被管理员编辑，则拒绝自动回退，需要人工审查。已回退的 v1 不允许再次直接安装，防止覆盖回退后编辑，需使用新版本。

数据库新增字段无需回滚删除；如需 UI 回退可使用既有 `VITE_PORTAL_UI=classic`。回退教学目录与回退视觉风格是两个独立动作。

## 验证

自动化包含清单数量/成熟度、危险路径、演示数据拒绝、备份失败、重复导入、ID 冲突、后续编辑保护和保留历史的回退。完整 `npm run check` 包含这些测试。

本地深度回归：在 `apps/api` 中运行 `npx tsx src/scripts/verify-morph-catalog.ts`。该脚本限制本地数据库，在必定回滚的事务内创建临时账号，验证四类测试账号目录可见、筹备课拒绝选课、三课时一节完成为 33%、时长与今日任务更新、作品提交门槛、旧链接以及课程/工具搜索；不调用模型。

本次本地导入前后对报名、进度、笔记、任务、提交、作品、作品素材、工作流运行表做计数/校验摘要核对，结果一致，14 个已发布案例保留。校验快照和浏览器截图均位于忽略目录，不提交到 GitHub。

## 后续

### 2026-10-16 文案与视觉终校

`morph-tool-copy-v2` 单独保存交接包 19 个工具的完整简介和副标题，不改写已安装 v1 清单及其校验值。`catalog:install` 在 v1 完成后自动应用该小版本；同版本重复运行不覆盖后续管理员编辑。执行前备份原始文案；缺少条目、文案已经被编辑或版本不匹配时停止。`catalog:copy:plan` 可单独预检，`catalog:copy:rollback` 可恢复这一次文案修订，但遇到修订后编辑会拒绝覆盖。若需回退整个目录，先恢复文案修订，再按原有目录回退流程预检；不要绕过编辑保护。

工具说明按用户要求恢复交接包原文，不表示平台重新验证了供应商性能、价格、免费额度或地区可用性；价格字段、虚构收藏和推荐标记不导入。按钮统一使用实际工具名称。13 门课程的名称、简介、分类、难度值、时长与封面逐项核对；“专家”展示、课程代码、查看详情/学习双入口和指定关联预览已补齐。试学/筹备状态、教师署名待确认及真实个人进度属于明确保留的业务差异，不仿造交接稿的演示记录。

教研人员需审阅三门讲义、确认署名、补充教学媒体与合法授权，再通过单独的内容版本升级正式发布。其余 10 门逐门补齐内容，不批量伪造课程完成度。课程与工具的关联是本轮编辑建议，非交接稿已确认先修条件或实际 API 能力；专业画像只采集真实学习和实践记录。
