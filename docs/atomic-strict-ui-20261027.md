# 原子课程 UI 严格还原修订

本修订替代上一轮课程网络的规则网格布局。目标页仍为用户指定的：
https://morph-lab-design-platform.wj27398.chatgpt.site/atomic-courses-particles

## 还原范围

- 使用目标页原始课程网的节点位置、三处黑色课程锚点、曲线连线、贡献者头像、纸片插画与缩放算法。
- `atomicReferenceNetwork.json` 保存经白名单提取的静态元素和样式；React 创建节点，不注入 HTML 或执行源站脚本。
- 原图连线与 13 件图片资源保存在 `public/morph-course-network/strict/`，无外链图片。
- 原稿课程网作为交接方案的课程结构导航。点击方向节点后查找平台已发布资源；无对应内容时明确说明，不伪造公开课程或学习记录。
- 完整课程、个人学习、贡献、心得、附件、审核、评价、刷新、进度筛选等保留在搜索框右侧“学习与管理”菜单；详情和编辑页保留现有流程导航。
- 分类与即时搜索采用原稿的 3:1 分栏；双列卡片使用原稿封面、字号、间距、收藏图标和底部操作。作者、内容、数量和学习状态仍为本地真实数据。
- 卡片收藏仅保存在本机浏览器，按账号区分，按钮标题已说明。收藏不会作为学习完成证据。

## 验证与界限

浏览器检查方向节点跳转、菜单进入教师编辑及附件、即时搜索、清除筛选、收藏切换、详情 Esc、心得关联原子与附件通过；1280、1440、1920 桌面视口无页面横向溢出，页面异常为零。原子回归、全站页面回归和构建结果见本机测试日志及根目录 `design-qa.md` 的最新修订记录。

源站 17 个设计样例与本地 9 个已发布原子属于内容差异，不将样例百分比或作者导入学习数据库。站点导航仍保留已接通的全站搜索和真实登录账户。本批变更不包含数据库内容重置、发布状态调整或腾讯云部署。
