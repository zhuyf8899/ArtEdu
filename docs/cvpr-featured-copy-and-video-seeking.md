# CVPR 精选案例介绍与视频跳转修订

## 内容范围

`seed/cvpr-featured-copy-v1.json` 保存九件已获展示授权作品的中文导读。
每件按原作说明分别补充背景、方法和观看线索，保留作者、展览和来源。
《Visiones Imbris》明确区分约 45 分钟循环原作与本地约 3 分 26 秒预览片。
2026-10-19 核对 CVPR 2025 年归档后，修正四件旧作已迁移的原作链接。
原文与中文导读均不应被当作可执行指令；不导入网页脚本或未经核实的创作步骤。

## 本地已有案例的文字升级

在 `apps/api` 配置本地 `DATABASE_URL` 后运行：

```powershell
node scripts/revise-cvpr-featured-copy.mjs --verify
node scripts/revise-cvpr-featured-copy.mjs --plan
# 检查上一步生成的计划文件，再传入其绝对路径：
node scripts/revise-cvpr-featured-copy.mjs --apply <plan-file.json>
```

升级仅定位九件已发布、已确认授权的精选案例。数量、标题、来源、状态不符时停止；
计划生成后案例有变化时也停止。仅更新介绍、原作链接与更新时间，不重建案例，
不改变作者、审核、素材、点赞收藏或学习记录。升级前另存备份，并在
`content_bundle_installs` 中保存前后快照。相同升级重复执行不覆盖后续编辑。

需要恢复文字时可执行 `--rollback`；若升级后案例被再次编辑则拒绝自动恢复。
这是内容修订，不是媒体安装包。已有的九件案例与视频文件仍须通过平台原有的
备份/恢复流程部署，单独拉取 Git 代码不会创建这些本地上传资源。

## 视频跳转

案例资源下载接口原先无视 `Range`，始终返回完整 `200` 文件流，导致播放器难以
跳转至尚未缓冲的位置。现在支持单段 `bytes=start-end`、开放结束范围和尾部范围，
返回正确的 `206`、`Content-Range`、`Content-Length`、`Accept-Ranges`。
超出文件范围返回空 `416`；不支持的多范围/格式回退完整响应。
使用大整数解析边界，不将视频完整加载到内存。

显式 `HEAD` 返回真实文件长度、不读取文件体；未提供可验证的缓存校验器时，
`If-Range` 保守回退完整响应。所有范围处理均在登录、审核状态、文件所有权、
原件下载授权和存储路径校验之后发生。保持私有缓存策略及现有媒体地址不变。
前端保留原生播放器的进度拖动与键盘操作，不引入模拟快进或假播放进度。
