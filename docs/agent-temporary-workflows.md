# Agent 临时工作流

Agent 可生成平台 API 节点图、读取和修改本人临时草稿，以及加载本人最新未发布正式草稿为临时副本。原生 ComfyUI 保留离线交换能力，不作为 GPU 执行入口。Agent 没有临时图执行或正式保存工具。

## 保存与执行

- 浏览器 IndexedDB 自动保存完整节点图、输入 PNG、遮罩和执行成果。聊天记录只引用临时图 ID；同一浏览器、同一账号可重新查看，不自动跨设备同步。
- 云端临时图、图片及成果只存进程内存。空闲 20 分钟后清理；编辑、执行、下载续期，查询和后台轮询不续期。此规则仅适用于新临时工作流，不改变原有缓存规则。
- 服务重启或临时副本过期后，查看仍读取本机内容；下一次编辑或执行时，从浏览器恢复图和所需输入。
- 卡片提供节点图、参数和变更摘要。每次执行必须点击“确认执行此版本”，才进入 API 调用和现有额度检查。
- “保存正式草稿（云端）”是唯一写入正式工作流版本的入口。既有正式草稿需仍属于本人且最新版本仍未发布，并检查载入时的版本 ID，避免覆盖他人更新。管理员也不能绕过所有者限制。
- “清理云端临时副本”仅清理该临时内存副本，本机内容保留。

## 内存预算与审计

`TEMPORARY_WORKFLOW_USER_MB=20`、`TEMPORARY_WORKFLOW_TOTAL_MB=128`，单位 MiB，可通过 API 服务环境变量调整。预算包含图定义、文本结果、二进制素材及执行中的结果预留。达到上限拒绝新增内容或模型调用，不淘汰未过期成果；相同输入文件复用已有二进制。单图片上限 8 MiB，模型调用前预留图片输出空间。

临时图不写入 `workflow_versions` 或 `workflow_runs`，生成成果不写入 `generation_outputs` 或文件缓存。生成任务仍保留任务状态、模型 ID、用量与计费摘要，提示词替换为临时任务标识。Agent 工具审计仅存操作名称、图 ID、版本及节点/连线计数，完整图通过独立 SSE 消息交付浏览器。永久入库需用户主动保存。

内存预算按 API 进程计算；当前方案面向单 API 实例，多个实例不共享图或预算。浏览器数据被清理后，已过期的云端内容无法恢复。浏览器保存失败会显示错误，不应将错误提示当作已备份。

## 验证

- API 安全回归包含本人权限、版本冲突、正式保存锁、空闲清理、恢复、下载续期、执行幂等、账号/服务预算、调用前拒绝、摘要审计及真实 Agent Harness 工具链（模型为模拟实现）。
- `node scripts/verify-temporary-workflow.mjs` 使用隔离 Chrome 与模拟 API，验证本机刷新、查看零云端请求、明确点击执行、过期恢复、无自动正式保存、本机成果及移动宽度。
- 已接入百炼北京地域 `wanx2.1-imageedit`（`wanx-image-edit` 协议），2026-10-22 通过一次真实 512×512 原图＋遮罩调用；产物使用内存返回。也可配置支持 `images/edits` 的兼容通道，均须显式启用 `imageEditing`。不能用仅支持文生图的通道替代。
