# 原子学习专业画像第一版

入口：`/my-learning?view=portrait`。沿用前端六个专业方向，以教学原子的 `direction` 和 `knowledge` 组织学习内容；方向可选以兼容旧原子，旧内容显示待标注。

新增认证接口 `GET /api/atomic/portrait`：只返回已发布教学原子的公开版本与当前用户已学的历史发布版本。进度、反馈按当前身份隔离，未返回其他用户提交或正文附件。接口读取现有原子学习表，无数据库迁移。

画像按原子去重，显示最新已学版本并保留各已学版本证据，不汇入旧课时、作品、收藏或工具点击。支持方向筛选、节点/列表浏览、证据详情、回到具体原子版本和添加学习计划。原子详情提供返回画像入口。

验证：前端生产构建、API 类型检查、画像去重与历史版本测试、既有原子学习与个人空间测试。

当前节点视图是方向筛选后的原子知识卡片；跨知识点关系连线、缩放、完整前置路径推荐与结构化计划回链仍属于后续迭代。知识点使用原子现有标签，尚未替换为公共知识图谱的规范 ID。
