# 通用课程知识图谱（2026-10-08）

## 交付范围

“我的学习 → 知识图谱”默认显示独立的通用课程图谱，不再等待管理员上传课程或绑定任务点。
从右上角“个性化图谱”进入原有学习证据、工具轨迹和成长推荐；“返回通用图谱”可返回。

- 默认地址：`/my-learning`。
- 个人扩展：`/my-learning?atlas=personal`；支持浏览器前进、后退。
- 独立课程分图：`/my-learning?atlas=course&atlasCourse=atlas-type`（示例：字体与版式）。`atlasCourse` 是静态图谱 ID，不与数据库 `course` 参数混用。刷新、浏览器前进/后退保留分图。
- 两种图谱仍使用平台既有登录权限。通用图谱与个人学习接口加载/失败隔离，未开放匿名访问。
- 无数据库迁移、数据初始化、进度写入、模型调用或新增依赖。
- 不更改现有课程、九个案例、账号、任务点与历史学习记录。

## 资料与内容边界

依据用户提供的《AI课程设计.zip》十个目录、24 份实际 PDF 整理。
使用 PDF 阅读和页面渲染核对目录、章节标题与关键内容；部分扫描教材无可提取文字，采用页面视觉核对。
这是人工编辑的通用路线，不是 LightRAG 自动生成、教材全文、完整阅读报告或经过教研审定的正式课程大纲。

代码仅包含概念摘要、书目标题、核对范围和原创练习建议，不包含教材页图、原始 PDF、网盘地址、来源水印、授权备注或压缩包。
原始资料与本地核对产物保存在 Git 忽略的私有目录 `apps/api/data/qa/course-atlas-source/`。
源文件 `curriculumAtlas.js` 中的 `sources.inspected` 可用于内容复核；页码为 PDF 文件页序，不是书内印刷页码。

总图保留十门课程的概览和 13 条课程关联（九条建议路线、四条知识迁移）。
本轮增加十张独立课程分图，共 40 个知识主题、95 个具体知识点及 20 项平台建议练习。
主题划分、短解释和练习是人工编辑整理，并非教材章节逐项复制或已审定课程大纲。
分图保留同一套排版语言，但主题数量、知识内容、分支数量和练习连接依课程而不同。
阶段、连线、练习和 AI 辅助方式均为平台编辑建议，界面明确提示非强制先修/必修顺序，不宣称原教材教授了特定 AI 工具。
陶瓷和电路练习要求教师指导和安全验证，不提供生成式配方、危险接线或烧制参数。

## 功能与状态说明

- 三组布局：理解设计、选择方法、进入创作；五种淡色表示知识方向，不表示熟练度。
- 总图圆形节点显示课程和方向，点击直接进入独立课程分图；概览卡也提供“查看课程知识图谱”。
- 分图按“课程 → 知识主题 → 具体知识 → 建议练习”展开，每个圆点可点击查看解释、资料依据与练习成果；点击后定位详情，有“返回图谱节点”。
- 分图实线表示知识归属；虚线表示平台建议将该主题用于练习。为避免穿过圆点，虚线从主题的最后一个显示知识点引出；该位置不是强制先修、完成标准或教材的教学顺序。
- 分图资料引用只使用所属课程已核对的资料 ID；练习明确为平台建议，不冒充教材原有作业。烧制和电路不提供未经验证的参数、配方或危险接线。
- 分图可切换十门课程、定位节点、显示/隐藏建议练习和切换清晰原尺寸；不会用查看行为更新学习进度。
- 分图主题/具体知识/练习三种颜色仅区分角色，不表示已学或掌握。进入分图后选中状态与节点详情按课程重置，避免串课。
- 总图和分图圆点在按下时保留中心定位，隔离平台通用按钮动效，防止小屏点击瞬间移位；浏览器回归覆盖按下/释放的真实鼠标坐标与位置稳定性。
- 分图宽屏按画布适配（最低 85% 保证文字可读），空间不够时在框内水平滚动；不缩小到不可阅读、不产生页面整体横向溢出。
- 无效分图 ID 显示提示和总图，不静默冒充其他课程。
- 可按五个方向筛选；搜索涵盖课程、主题、95 个知识点及书目名称，多个词按交集匹配。
- 未命中有“清除筛选”；筛选不移动节点，未匹配节点降亮并禁用。
- 宽屏自动等比例适配整张图谱；小屏保持节点文字大小、在框内水平滚动，课程选择框可直接定位节点；页面自身不横向溢出。
- 关联建议可以直接选择下一课程；不会写入学习进度或把“已查看”当作“已掌握”。
- “查找平台课程”只检索已发布平台内容，不伪造数据库课程 ID，不声称十门方向已上传、已授权公开下载或已开课。
- 个人学习接口失败只影响个人视图，有明确重试提示；可随时返回通用图谱。最近资源接口失败不再隐藏主要学习记录。

## 扩展方式

### 2026-10-08 可读性与浏览体验整改

- 课程分图只保留课程标题与返回/切换入口，取消重复的大标题。
- 初次打开、窗口尺寸变化和重置后定位当前节点；返回总图时保留所选课程并重新对齐，避免小屏只看到无关课程。
- 画布在页面内上下左右滚动，提供缩放、适应宽度、重置与当前节点定位。默认小屏 100% 保持文字可读，缩小预览会明确提示放大阅读。
- 增加按主题折叠的知识目录，不必在小屏拖动画布才能阅读。
- 节点详情使用原生 dialog：桌面右侧面板、手机底部面板；焦点进入详情标题，Escape/关闭返回触发节点，浏览不跳到页面底部。
- 单门课程节点显示本课程已完成课时；个人图谱详情单独显示跨记录的“阶段累计目标”，颜色和阶段百分比不是知识掌握度。
- 保留 95 个知识点的资料依据和建议练习，不自动猜测与已发布平台课程的绑定。关键词搜索明确标为检索，未配置课程不显示虚假的“开始该课”入口。

1. 教研确认知识点与关系后，版本化更新通用数据。`atlas-*` ID 独立于数据库 ID，不按标题自动猜测个人学习进度。
2. 后续建立经管理员确认的通用节点与平台课程/课时映射，只有明确的学习事件作为个人图谱证据。
3. 可以继续在个人扩展中加入推荐解释与工具路径；通用图谱始终可在没有个人数据时使用。
