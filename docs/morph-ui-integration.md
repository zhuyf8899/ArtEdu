# MORPH LAB v17 前后端接入（2026-10-16）

## 入口与部署

- 新界面：`http://localhost:4173/morph/`。原 React 门户、图谱、工作流和后台入口继续可用。
- `8086` 是最初交接包的独立静态预览，不是接入后的业务入口。
- 本地先启动数据库，再运行 `npm --prefix apps/api run db:migrate` 和项目启动命令。Docker 根配置只负责数据库。
- 部署构建会将 `admin-console/public/morph` 自动复制进前端产物，现有 Nginx 可提供 `/morph/`，API 继续使用同源 `/api`。
- 目标环境必须执行新增迁移 `0037_morph_workspace_state.sql`；仅推送前端文件不足以启用新草稿保存接口。
- 本地 `.env` 的允许来源是 `http://localhost:4173`，请使用此地址；若改用 IP/其他端口，需要按既有规则配置对应的 CORS_ORIGIN。没有放宽会话与跨站写入校验。

## 新状态表的边界

`morph_workspace_state` 只保存新 UI 特有的 profile、课程/工具 favorites、remixes、tool-submissions、curriculum-paths、creation-records。原课程进度、笔记、案例收藏、作品及上传文件继续使用原业务表与权限。

每个状态按登录用户隔离，严格校验字段，使用乐观版本锁阻止旧页面覆盖新数据；保存成功后才确认。保存失败保留表单输入；AI 已生成但未保存的输出可单独重试保存，不自动重复调用模型。个人背景图在浏览器压缩后保存，限制约 650KB；服务端对每个状态另有 800KB 总量限制。

课程目录推荐是规则匹配，未宣称模型自动编排；工具推荐目前是个人草稿，未新增公共投稿审核队列。新对话记录与原 React 页的 IndexedDB 历史相互独立，没有自动迁移或覆盖旧对话。
