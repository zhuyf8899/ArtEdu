## 已处理

- 登录与会话失效：保留当前路径和查询参数，重新登录后继续目标页；登录错误保留具体原因。
- 节点画布：查看工作流不再立即创建运行；显式开始后运行 ID 写入地址。退出回到列表；刷新与浏览器前进后退可恢复管理列表、编辑画布或运行记录。
- 快速切换：旧工作流/课程请求不覆盖新页面，编辑目标变化时清除旧画布。
- 课程详情：课程和课时由地址定位，返回课程库清除详情参数，浏览器返回恢复详情。
- 文件链接：普通点击平台 API 文件链接时先检查访问权限，失败保留当前页并显示原因；登录失效进入保留目标地址的登录页。
- 退出登录：失败反馈且保留当前登录界面状态，避免假退出。
- 无权限管理页：提供返回学习空间及切换账号入口；运营账号默认进入审核页。
- 未知地址：显示页面不存在及返回首页入口。
- 入口文案：工作流管理/创建、草稿画布及指定工作流入口与实际目标一致。
- 流式接口：401/403/429/500 及成功但非流响应不再无条件重提请求；仅明确不支持流接口的 404/405/501 使用兼容路径。
- 已退出课程不再返回可打开的材料链接，减少展示可访问但点击被拒绝的误导。

## 地址约定

- `/studio`：设计工具列表。
- `/studio?builder=1`：工作流管理与创建。
- `/studio?builder=1&edit=<id>`：编辑指定工作流。
- `/studio?workflow=<id>&run=<id>`：工作流及已有运行；省略 run 只查看画布。
- `/admin/workflows?edit=<id>`：管理端编辑画布。
- `/learning?course=<id>&lesson=<id>`：课程及课时。
