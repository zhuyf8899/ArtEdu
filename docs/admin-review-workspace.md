# 作品审核工作区改良（2026-10-13）

## 目标和范围

旧页面固定在右侧约 540px 的窄抽屉中，正文、授权与作品文件堆叠，审核按钮需要滚动到末尾才能使用。本轮仅调整作品审核页面及共享作品组件的可选显示配置；不改变审核权限、数据库状态、额度管理、课程或公共案例的默认展示。

## 页面与交互

- 队列显示真实状态数量、标题、提交者、时间、缩略图和需要核对的资料项；支持搜索与无结果清除。
- 详情改为居中的宽屏工作区，白底、细边框、低饱和状态提示。桌面左侧预览作品，右侧核对作者、来源、工具、授权等资料；手机纵向排列。
- 页头和底部操作栏固定在窗口内，仅中间内容滚动。支持上一件、下一件；未提交备注按作品隔离，在当前工作区切换时保留，关闭后清除，不写入数据库。
- 长简介仅在实际超出四行时提供展开入口。授权说明、私有编辑备注、生成提示和文件清单按需展开，不混入公共作品正文。
- 未加载完成、加载失败、作品已处理或状态不一致时禁止审核。失败可重试。驳回必须说明原因，备注上限与服务端一致为 1000 字；通过和驳回仍经过原有最终确认及服务器校验。
- 审核窗口支持键盘焦点约束、Esc 关闭和关闭后焦点恢复。图片预览与最终确认打开时不会误关背后的审核窗口；取消确认不会提交审核决定。

## 验证

自动回归入口：`npm run check:web`，包含 `tests/review-workspace.test.mjs`。

本地浏览器验证：`node scripts/verify-review-workspace.mjs`。需本地 API、数据库和前端已经启动，并在 Node 模块搜索路径提供 Playwright（使用已安装的 Edge）。仅支持 loopback 地址；可通过 `ARTEDU_TEST_ORIGIN` 设置端口，通过 `ARTEDU_TEST_PASSWORD` 设置本地演示管理员密码。浏览器 GET 响应中的待审核状态为临时测试副本，真实审核 POST 请求全部拦截，测试不会发布或驳回实际案例，也不会执行生成任务。

已验证 1440×900、1092×764、768×1024、390×844、844×390：窗口不越界，正文不横向溢出，页头与操作栏不重叠。覆盖备注隔离与返回保留、确认取消、图片预览返回、加载失败重试、状态变化后禁止操作。截图与几何检查保存在被忽略的 `apps/api/data/qa/review-layout/`，不随仓库公开上传。

检查步骤及结果：1）审核队列搜索与状态选择正常；2）打开真实已通过作品，双栏核对、长简介展开和图片预览正常，操作栏可见；3）浏览器模拟待审核作品，备注校验、最终确认取消及错误恢复正常。前端构建通过，自动测试共 134 项通过（Sites 6、聊天/图片 37、平台 91）。

当前数据库没有待审核作品，因此操作路径采用浏览器内模拟验证；不宣称已经对真实案例执行审核。实际已通过案例使用管理员登录进行只读查看。未执行完整 WCAG 审计。
